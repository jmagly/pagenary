# Rollout blueprint

Follow this weekly cadence to keep Nimbus deployments predictable across regions.

- Assemble launch pod (solutions engineer, operations manager, compliance lead).
- Map fulfillment center topology and existing fleet integrations.
- Run connectivity survey and verify telemetry bandwidth for critical lanes.

## Four-week timeline

1. **Week 1** — Import SKU orchestration templates and validate staging data.
2. **Week 2** — Run staged dry-runs through the simulator and capture exceptions.
3. **Week 3** — Promote automation flows to production with guardrails enabled.
4. **Week 4** — Activate SLA alerts and handoff to regional operations.

### Handoff checklist

- Signed MSA and data processing addendum on file.
- Access to the control plane scoped via SSO groups.
- Dual uplinks tested with simulated outage scenarios.
- Reporting dashboards shared with regional leadership.
