# Specifications

Numbers for the standard bench-class interocitor. Field and station classes scale
the emitter count and power budget; the geometry stays the same.

## Array

| Parameter | Value |
| --- | --- |
| Focal emitters | 3 (matched set) |
| Reference oscillator | Single, thermally stabilized |
| Phase error (calibrated) | &lt; 2 mrad across triad |
| Settling time | &lt; 400 ms, range-independent |
| Aperture diameter | ~14 mm at focus |

## Power

| Parameter | Value |
| --- | --- |
| Standby draw | 90 W |
| Active sweep | 2.1 kW peak |
| Containment ring | 40 W (interlock + field) |

## Environment

| Parameter | Value |
| --- | --- |
| Bench level | within 1 arc-minute |
| Operating temp | 5–35 °C |
| Warm-up | one full thermal cycle |

All figures are nominal for the showcase. Real arrays ship with a calibration
certificate; these do not, because they are make-believe.
