# Contact

Interocitor Labs is a fictional company invented to show how far a Pagenary site
can be pushed with configuration alone. There is no array to order and no band to
hail.

If you'd like to build a real docs site that looks like this one, the recipe is
no secret:

- A custom dark `theme` object
- A `hybrid` `navPosition`
- A two-part wordmark and a tagline

Copy the interocitor config (`examples/interocitor/config.json`), point it at
your own content, and run `npm run build:tenants`.

For the toolkit itself, see the Pagenary documentation under `docs/` — in
particular the theming gallery (`docs/THEMING-RECIPES.md`).
