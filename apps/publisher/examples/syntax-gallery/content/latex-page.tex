\section{Semantic structure}

The portable gallery profile converts sections, emphasis, lists, tables, links, and mathematics to HTML
and MathML. The standard web profile supports a broader qualified corpus when LaTeXML is installed.

\begin{itemize}
  \item Semantic HTML remains the canonical page output.
  \item Renderer execution is local and bounded.
\end{itemize}

\section{Bounded controls}

The tenant selects a versioned HTML profile, failure policy, timeout, output
limit, and package allowlist. Unsafe file, network, shell, traversal, and package
operations are rejected before the isolated converter runs.

\section{Optional PDF sibling}

When the tenant enables \texttt{pdf-v1} and local Tectonic is available,
Pagenary adds a content-addressed PDF download. HTML and MathML remain the
primary accessible page. Under the gallery's warning policy, unavailable PDF
tooling produces a diagnostic without removing the HTML page.
