# Share Icons

This directory contains the default local icon assets for the Pagenary share menu.
Each built-in target has a full-color SVG in `color/` and a monochrome SVG in `mono/`.

Most brand paths were generated from Simple Icons package data during development.
Simple Icons path data is CC0-1.0; brand names and logos remain trademarks of their respective owners.
Utility actions and services unavailable in the acquired Simple Icons set use local fallback marks.
